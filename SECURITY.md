# Security reporting

Report concerns privately through https://maretha.io/contact. Do not post credentials,
client content or sensitive logs in public issues. For upstream reporting policy, consult
https://github.com/nuxeo/nuxeo-mcp-server/security/policy.

This Labs fork retains upstream runtime behavior and is not a security certification.
Review client/server authentication, Nuxeo account privileges and network exposure before use.
